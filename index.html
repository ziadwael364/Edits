Publish straight to GitHub

Fill this in once and Publish Changes will push updates directly into your GitHub repo — GitHub Pages picks them up and rebuilds automatically, usually within a minute or two. Leave it empty and Publish Changes will just download a zip for you to upload by hand instead.

Creating a token: on GitHub go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Set "Repository access" to Only select repositories and pick this repo, then under Permissions set Contents to Read and write. Paste the token above — it's stored only in this browser (localStorage) and sent only to GitHub's API, never anywhere else. Don't do this on a shared or public computer, and you can revoke the token any time from that same GitHub settings page.
How publishing works: everything you do here saves to this browser only (localStorage + IndexedDB), so you can preview changes safely — a visitor on another device won't see them. Publish Changes either pushes straight to GitHub (if Publish Destination above is filled in) or downloads an update package for you to upload manually — see README.txt inside it for exact steps either way.
